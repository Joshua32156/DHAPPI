# D.Happi - Application Web

Ce projet est une application web moderne construite avec React, Vite et TypeScript.

## Technologies Utilisées

- **Framework :** React 18
- **Outil de Build :** Vite
- **Langage :** TypeScript
- **Style :** Tailwind CSS
- **Composants UI :** shadcn-ui, Radix UI
- **Routage :** React Router
- **Animations :** Framer Motion

## Démarrage Rapide

### Prérequis

Assurez-vous d'avoir [Node.js](https://nodejs.org/) installé sur votre machine.

### Installation

1. Clonez ce dépôt ou accédez au dossier du projet :
   ```sh
   cd "D.Happi"
   ```

2. Installez les dépendances :
   ```sh
   npm install
   ```

### Lancement du serveur de développement

Pour démarrer le projet en local avec rechargement à chaud :

```sh
npm run dev
```

L'application sera accessible par défaut à l'adresse locale indiquée dans votre terminal (généralement `http://localhost:8080` ou `http://localhost:5173`).

### Construction pour la production

Pour générer une version optimisée pour la production :

```sh
npm run build
```

Les fichiers générés se trouveront dans le dossier `dist/`. C'est ce dossier qui doit être déployé sur votre serveur.
